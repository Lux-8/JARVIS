# JARVIS — Голосовой ассистент на Python

Модульный голосовой помощник для управления компьютером, выполнения системных команд и автоматизации повседневных действий.

## Архитектура проекта
Код разделён на независимые модули для удобства поддержки и расширения:
* `main.py` — точка входа и главный цикл работы ассистента.
* `assistant.py` — основная логика обработки запросов и взаимодействия с пользователем.
* `speech.py` — модуль распознавания и синтеза речи.
* `commands.py` — набор поддерживаемых команд и действий.
* `config.py` — конфигурация и настройки параметров.
* `utils.py` — вспомогательные функции.

## Запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите необходимые библиотеки (для работы со звуком и распознаванием речи) и запустите главный файл:
   ```bash
   python main.py
   ```
